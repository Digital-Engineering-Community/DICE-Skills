**MANDATORY** when verifying sources, fact-checking claims, or conducting analysis.

## REGULATION

**Stage 1. Identification:** Formulate the main claim, decompose into atomic claims, classify by type, filter out opinions, assess significance. See "Stage 1. Identification".
**Stage 2. Method Selection:** Match claim type to method set: minimal (routine question) or full (publication). Matrix: `references/applicability-matrix.md`. See "Stage 2. Method Selection".
**Stage 3. Verification:** Execute methods, search via web (two independent queries per fact), minimum 2 sources per fact, check for hallucination. See "Stage 3. Verification".
**Stage 4. Classification:** Assign category: ✅ confirmed / ⚠️ factoid / 🔴 conflicting / ❓ unconfirmed / ❌ refuted. Cite sources with dates. See "Stage 4. Classification".
**Stage 5. Synthesis:** Compile report: claim, verdict, sources. Flag gaps, do not smooth over conflicts. See "Stage 5. Synthesis".

**MANDATORY. Rules:**
1. Never generate numbers — only from sources
2. Check source dates — flag outdated ones
3. Scan for sycophancy — do not agree with the user without verification
4. Fact-check your own claims before publication — mandatory
5. Red flag: repetitive fragments, corrupted structure — STOP, report to operator

**Exceptions:** 1) No sources on topic — record "unconfirmed", do not fabricate. 2) Contradiction in knowledge base — escalate to the `research` skill.

## Stage 1. Identification

### 1.0. Main Claim

Formulate the main claim of the text being checked. For a skill — "the method set is sufficient for the task". For a post — "the argument proves the conclusion". For a report — "conclusions follow from data". Verify the main claim first, using Popper (seek disconfirmation — method description in "Stage 3. Verification"): what would have to be true for the main claim to be false? If the main claim is not confirmed — stop, details do not matter.

### 1.1. Atomic Claims

Decompose the text into minimal verifiable units. One claim = one verification. Example: "Acme Corp is a major player, revenue $860M, 48% growth" — decompose into 3 claims: (1) major player [status], (2) revenue $860M [figure], (3) 48% growth [figure]. Opinions ("seems", "probably", "I feel") — filter out, they are not fact-checked.

### 1.2. Classification by Type

Determine the type of each claim and select methods for verification. Description of each method — in "Stage 3. Verification".

**Figure** — a specific number, date, name, title. Example: "revenue $860M". Methods: SIFT, minimum 2 sources, Lateral Reading, statistical fact-checking, framing.

**Status** — a claim about the state of affairs: "the term is established", "the standard is adopted". Methods: Turing, Popper, minimum 2 sources.

**Cause** — a causal relationship: "X led to Y". Methods: minimum 2 sources, Popper.

**Forecast** — a claim about the future or an estimate: "the market will grow 3x". Methods: Fermi, Bayes, Popper, minimum 2 sources.

**Methodology** — assessment of the reliability of an approach, method, or school. Methods: Turing, Popper, Lakatos.

**Own inference** — a claim generated by the agent: hallucination, sycophancy, plausible generation. Methods: CoVe, anti-hallucination, anti-sycophancy, Bayes.

Result: for each claim, record the type and list of methods.

### 1.3. Significance (check-worthy)

Assess whether the claim affects the argument's conclusion. If not — mark as insignificant, do not spend tokens. Verify only semantic anchor points: figures the argument rests on; causal relationships; key terms. A fact that does not affect the conclusion — low priority. A fact that is the foundation of the argument — verify mandatorily.

**Stage 1 completion criteria:** main claim formulated and verified, each claim classified by type, minimal method set selected, opinions filtered out, significance assessed.

## Stage 2. Method Selection

Open [references/applicability-matrix.md](references/applicability-matrix.md), find the row for the claim type and match to the method set. Detailed description of each method — in [references/methodologies.md](references/methodologies.md). Philosophical context (Turing, Popper, Lakatos, Kuhn) — in [references/fact-checking-theory.md](references/fact-checking-theory.md).

**Minimal set** — for routine questions. Take only the methods selected by type in Stage 1.2.

**Full set** — for publications. Take the minimal set and add: Fermi (for all types), anti-hallucination (for all types), framing (for all types with numbers and estimates).

If results diverge at Stage 3 — return to Stage 2, add: source conflict — add Popper; unconfirmed — add Turing; factoid — add Lateral Reading.

**Stage 2 completion criteria:** method set (minimal or full) selected for each claim, selection justified.

## Stage 3. Verification

### Source Search

Formulate a search query and execute twice: once in the primary language, once in English. Extract content via web fetch; if the site blocks — use browser.

### Methods

Execute each method from the set selected at Stage 2:

**Minimum 2 sources (IFCN).** Cross-checking. Divergence — seek a third.

**Lateral Reading (Wineburg & McGrew, Stanford, 2017).** Verify the source from the outside: who is behind the site, what do others say, is there a conflict of interest. Do not trust the "About Us" page.

**SIFT (Caulfield, 2019).** Stop, investigate the source, find better coverage, trace to the original. Quick filtering.

**Fermi estimation.** Estimate the order of magnitude before searching. "10 billion users" — impossible. Filters out half the nonsense before the first query. Named after Enrico Fermi, popularized by Bergstrom & West (Calling Bullshit, 2020).

**Turing (operational criterion).** Formulate a verifiable criterion through an observable result. "The term is established" — criterion: is there a Wikipedia article, academic publications, a commonly accepted definition? If you cannot formulate a criterion — it is an opinion, not a fact.

**Popper (falsificationism).** Deliberately seek facts that would disprove the hypothesis. Not only confirming ones.

**Lakatos (research programs).** Assess which side predicts new facts, and which explains post hoc. A progressive program — predicts. A degenerating one — retrofits.

**CoVe — Chain-of-Verification (Meta AI, 2023).** For the agent's own inferences — execute the subprocess: (1) formulate a verification question for each claim, (2) answer each question independently, without looking at the initial answer, (3) compare: do the answers match? Divergence = hallucination, (4) generate a corrected answer based on verified data.

**Anti-hallucination.** Check: (1) the source exists — find it via search, do not trust the model's memory, (2) the quote is accurate — open the original via web fetch, compare verbatim, (3) the figure is from the original — check the context, are there truncated data, a different year, a different market.

**Statistical fact-checking.** For claims with numerical data: check effect size (is the result clinically significant?), GRIM test (do the mean, N, and proportions converge?), Benford's law (distribution of leading digits in natural data). "Minimum 2 sources" will not help if both cite the same erroneous report.

**Anti-sycophancy.** Separate from hallucinations: check whether you agreed with the user's claim contrary to the found facts. Method: formulate the user's position, find facts against this position via search, compare. If facts contradict — explicitly state the discrepancy, do not fit the conclusion.

**Bayes.** For forecasts and own inferences: what is the base rate of the event? From past forecasts of a similar type — how many came true? A positive test for a rare event does not mean high probability. Example: "the market will grow 3x" — if out of 10 past forecasts of 3x growth, 1 came true, the base rate is 10%. An authoritative source does not mean confirmation.

**Framing.** "90% survival rate" vs "10% fatality rate" — the same number. Check the framing, not just the number.

**Stage 3 completion criteria:** each claim verified by selected methods, sources cited with dates, hallucinations identified and corrected.

## Stage 4. Classification

Assign each claim one of five categories:

- **Confirmed** (✅) — confirmed by at least 2 independent sources, with a primary source
- **Factoid** (⚠️) — widely circulated, but without a reliable primary source
- **Conflicting data** (🔴) — sources diverge
- **Unconfirmed** (❓) — insufficient data
- **Refuted** (❌) — demonstrably false

Cite sources with publication dates.

**Stage 4 completion criteria:** all claims classified with a marker, sources with dates.

## Stage 5. Synthesis

Compile verified facts into a final report. Format for each fact: claim, verdict, sources with dates. Explicitly flag everything that is unconfirmed.

When sources conflict — show both positions, do not reduce to a common denominator (Kuhn, paradigms). Show different frames of reference.

Assess the "research program" (Lakatos): which side predicts new facts, and which explains post hoc.

**Stage 5 completion criteria:** gaps flagged, conflicts not smoothed over, result produced.
